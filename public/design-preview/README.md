# GiftGrid homepage design preview

Presentation preview of the live homepage captured on 5 September 2026. Production and the existing application files are unchanged.

Open `/design-preview/index.html` through a static server. The preview preserves the live section order, content, imagery and audience panels. Its CSS applies Next SaaS-inspired section spacing and a light, consistent type hierarchy using GiftGrid's navy, blue and white palette. Hero, image-card, CTA and footer heading contrast is corrected.

Audience tabs support mouse and keyboard interaction; mobile navigation supports opening, closing and Escape. Application, booking and navigation links lead to the live website. This is a visual review artifact, not a replacement application. Original stylesheets and images are loaded from the live site and require a network connection.

Files: `index.html`, `preview.css`, `preview.js`, `desktop.png`, `mobile.png`.

Verified in Chromium at 390, 768 and 1440 pixels: no horizontal overflow, no broken images or JavaScript errors, working audience tabs and mobile navigation, white hero heading.

Reference: supplied Next SaaS v2.6.0, cloud-software template (section spacing and typography). No template marketing content or new claims were added.
